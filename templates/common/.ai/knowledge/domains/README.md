# 业务领域页(横向视图)

每个业务领域一页:`<领域名>.md`。领域页承载**多个入口共用的规则**、无对外入口的后端行为,以及实体、数据归属和状态流转。

**提升规则**:规则首次出现时写在入口页;第二个入口也用到时提升到领域页,入口页原处改为链接。

## 页模板

复制以下结构新建 `<领域名>.md`:

```
# <领域名>

> 最后更新:YYYY-MM-DD

## 领域职责

## 实体与数据归属

| 实体 | 业务含义 | 归属 | 状态流转 |
|---|---|---|---|

## 共用业务规则

（被多个入口引用的规则写在这里,入口页只链接不复制）
```
