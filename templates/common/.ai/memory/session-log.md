# Session 日志(过程记录)

> 只记过程:做了什么、关键决策、下一步。**系统当前是什么样一律写进 `../knowledge/`,不在本文件重复。**
> 工程节点追加:完成可独立验收的需求点、做出关键决策或会话切换时追加;细碎代码步骤合并记录,只增不改。
> 跨工具(Claude Code ↔ Codex)切换前,必须确认本文件已落盘并 commit。

## 控制体量

- 需求点完成后,当前状态进 `../knowledge/`,本文件只留一行结论。
- 超过约 200 行时,把旧条目压缩成每个需求点一行,移入 `../knowledge/iterations.md` 的「已归档」。
- 不要把能从 knowledge 读出的内容再抄一遍。

## 条目格式

### YYYY-MM-DD HH:mm — <节点标题>

- 做了什么:
- 关键决策:
- 下一步:
